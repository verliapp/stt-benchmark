# Giggy evaluation archive: October 13–14, 2026

This directory preserves the previously published evaluation, packed transcripts,
and summary files byte for byte. `manifest.json` records their SHA-256 hashes.
The dataset summaries and latency file also contain the other providers present
at that snapshot; those records are retained unchanged.

The archived API metadata records what the service returned at that time. Giggy
attributed its Qwen label to a naming flag left over from earlier testing and
described its STT model as standalone. Neither the metadata nor that explanation
independently verifies model architecture.

Current results live in the main `results/` directory.
